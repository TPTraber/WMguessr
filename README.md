#WMGuessr360

WMGuessr360 is a GeoGuessr like game using 360 imagery taken by our team over the course of the hackathon.

[Try it out!!!](http://wmguessr.club/)

### Built with:
 - HTML
 - Javascript
 - CSS
 - Leaflet
 - Three.js


### What's next for WMGuessr360
- Adding multiplayer functionality
- Adding leaderboard scoring
